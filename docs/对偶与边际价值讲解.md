# 对偶变量、母线边际价值、ν：零基础讲解

> 面向非数学/非经济专业队友。本讲义是 `题1变量定义.md` §7 的"慢速版"：先人话和数字，后公式。
> 读完应能：(1) 说清"对偶变量"是什么；(2) 知道 λ、ν 各回答什么问题；(3) 看懂论文里三张对偶/边际相关图。

---

## 第一部分：概念从零讲起

### 1.1 我们的问题长什么样

题 1 本质上是一张填空题：

> 已知 24 小时（144 个 10 分钟时段）的电价、光伏、负荷，请决定每个时段**买多少电、充多少电、放多少电**，让**全天总电费最少**。

- **目标**：要压到最低的那个数——全天总电费；
- **约束**：填空不能乱填、必须遵守的规则，例如

$$S_t \le \overline S = 10800 \text{ kWh} \quad (\text{电池存电量不能超安全上限})$$

### 1.2 那句标准定义，逐词拆开

教科书对对偶变量的定义是：

> "把该约束的右端放宽 1 个单位，最优目标值改变多少。"

拆词：

| 词 | 意思 |
|---|---|
| 右端 | 约束写成"左边 ≤ 右边"，右端就是那个数字：10800 |
| 放宽 1 个单位 | 把 10800 改成 10801，即**给电池多 1 kWh 容量** |
| 最优目标值 | 在新容量下重新做一遍优化，得到的新的最低总电费 |

人话版：**"如果电池容量大 1 kWh，总电费能便宜多少？"**——就这一个问题。

### 1.3 思想实验：真的算一遍

假设容量 10800 → 10801，多出的 1 kWh 池内容量这样用（效率 η = 0.9）：

- **谷时段**（电价 0.3713 元/度）多充：要得到池内 1 度，母线侧须买 1 ÷ 0.9 ≈ 1.111 度，多花 1.111 × 0.3713 ≈ **0.41 元**；
- **峰时段**（电价 1.3952 元/度）多放：池内 1 度放出得母线侧 0.9 度，少买 0.9 度，省 0.9 × 1.3952 ≈ **1.26 元**。

一进一出，**总电费便宜约 0.84 元**。

### 1.4 对偶变量：每条约束自带的一个"价格"

上面算出的 **0.84 元/kWh**，就是"容量 ≤ 10800"这条约束的**对偶变量**（即文档 §7 的 μ^max 在电池充满时段的值）。

它有直接的用处：若厂家扩容报价 0.5 元/kWh，值得买（0.5 < 0.84，赚）；报价 1.5 元，不值。所以对偶变量就是**"这条规则卡得有多疼"的标价**：

- 卡得疼（容量不够用）→ 对偶变量是正数；
- 没卡到（电池从没充满）→ 对偶变量 = 0，扩容一毛不值。

求解器解完优化后，会**自动**替每条约束算出这么一个数，不用我们自己算。名字来源：求解器内部同时在解一个"镜像"的对偶问题，这些价格就是它的解。名字不重要，记住——

> **每条约束自动附带一个价格，告诉你把它松一格能赚回多少。**

一个比喻：约束像一道道闸门，对偶变量是挂在每个闸门上的牌子，写着"这道闸松一格值多少钱"。λ、ν、μ 就是不同闸门上的牌子。

### 1.5 "边际"是什么

"边际 (marginal)" 只有一个意思：**多 1 个单位，引起多少变化**。

- "多 1 kWh 容量 → 省 0.84 元"：0.84 就是**容量的边际价值**；
- "这小时多用 1 度电 → 总电费涨多少"：答案就是**母线的边际价值** λ。

## 第二部分：λ 和 ν 各回答什么问题

我们的模型里每条约束都有一个对偶变量，求解器输出的两个最重要的（见 `lp.py` `res.eqlin.marginals`）：

| 约束 | 对偶变量 | 人话问题 | 量纲 |
|---|---|---|---|
| t 时段供需平衡 | λ_t | **母线上多要 1 度电，总电费涨多少？** | 元/kWh |
| SOC 递推（电量怎么累积） | ν_t | **池内多存 1 度电，后续合计能省多少？** | 元/kWh |
| 容量上限 / 下限 | μ^max / μ^min | 容量多 1 kWh（下限再低 1 kWh）能省多少？ | 元/kWh |

### 2.1 λ_t：这小时电有多贵（"内部电价"）

λ_t 取决于那一刻"最后 1 度电是谁供的"（谁在边际上，谁定价）：

| 当时的状态 | 最后 1 度电的来源 | λ_t |
|---|---|---|
| 正在向外网购电（g_t > 0） | 外网 | 正好 = 电网价 p_t |
| 电池在放电 | 电池 | 电池的内部成本 ν_t / η |
| 正在弃电（w_t > 0） | 白扔的 | **0**，白拿不涨钱 |

所以 λ_t 像一条**系统自己形成的内部电价曲线**：白天贴着电网价，傍晚电池顶上时低于电网价，光伏爆满弃电时归零。电力市场里这个概念叫**节点边际电价 LMP**——我们单母线，就叫母线边际价值。

### 2.2 ν_t：池子里 1 度电值多少

λ 和 ν 的区别只在**计量地点**：

- λ_t：**母线上** 1 度电的价值（母线口径）；
- ν_t：**电池池内** 1 度电的价值（池内口径），水电站行业叫 water value。

换算 = 打效率折扣。母线买 0.9 度才变成池内 1 度：

$$\text{充电时段 } \lambda_t = \eta\, \nu_t, \qquad \text{放电时段 } \lambda_t = \nu_t / \eta$$

（代码注意：求解器原始输出带负号，`lp.py` 已做 ν = −ν^raw 的正号约定，正数 = 池内 1 度有正价值。）

### 2.3 三个名字的关系（一句话）

**对偶变量**是总概念（每条约束自带的价格）；**母线边际价值**是其中供需平衡约束那个对偶变量的经济学名字，符号 **λ**；**ν** 是另一条约束（SOC 递推）的对偶变量的符号。不是三个平行概念，是"总概念 → 名字 → 符号"。

## 第三部分：三张图怎么看（配 `plot.py`）

对偶相关的图共三张，颜色全项目固定：**p = 蓝实线，λ = 橙虚线，ν = 水青点划线**；背景淡蓝带 = 谷段（电价最低 1/3 时段），淡红带 = 峰段（最高 1/3）。

### 图 A `q1_duals.png`：对偶主图（单轴三条线）

游戏规则就一条：**盯橙线和蓝线的位置关系。**

1. **橙线躲在蓝线底下看不见** → 正在买电（λ = p，两线重合）；
2. **橙线明显掉到蓝线下面**（主要在峰段）→ 电池在放电，电池是比外网便宜的边际电源，λ < p；
3. **橙线贴零** → 在弃电，电多到白给；
4. **水青线（ν）总是平滑的** → 它是电池心里的"内部汇率"，不跟电价尖刺跳。充电时段 ≈ p/η（买 1.111 度才换池内 1 度），两次充放电之间保持水平。

一句话：**蓝线是外面世界的价格，橙线是小区内部的影子价格，水青线是电池心里的账。储能的作用就是把橙线从蓝线的高峰上削下来。**

### 图 B `q1_schedule.png`：三联调度图（价格 → 动作 → 结果）

- **上联**：p 与 λ 两条线 + **绿色半透明填充**夹在中间。填充 = 每时刻价差 p − λ，即"这小时储能当便宜电源替系统省下的钱"。绿面积大的时段 = 储能干活最猛的时段；
- **中联**（动作，与上联对答案）：黄柱向上 = 充电，粉柱向下 = 放电，绿线 = 购电。谷段黄柱出现处，上联橙线贴着蓝线；峰段粉柱出现处，上联橙线掉到蓝线下面；
- **下联**（结果）：绿台阶线 = 存电量 S_t，上下灰虚线 = 安全区 1200 / 10800。**台阶线贴到虚线 = 容量约束卡住的时段**，即闸门 μ 的牌子显示正数的时段。

### 图 C `q1_s0_sensitivity.png`：S₀ 敏感性（不是对偶图，思想相通）

横轴 = **强行钉死**的初始电量 S₀，纵轴 = 钉死后重新优化的总电费。绿圆点 = S₀ 自由时的最优费用 Z*；红方块 = 附录标定值 6000 处的费用（标注贵多少）；曲线在 8550 附近**平坦如盆地** → 初始电量在附近怎么挪费用几乎不动，说明"把 S₀ 当决策变量"收益有限。

与图 A 的关系：图 A 告诉你**每小时**电值多少钱（求解器免费送的对偶）；图 C 告诉你**初始电量这一个参数**值多少钱（重复求解硬扫出来）。思想上都是"边际"。

### 看图三问（口诀）

1. 橙线贴着蓝线吗？贴 = 在买电；掉下去 = 电池在放电；贴零 = 弃电。
2. 橙蓝之间的缝多大？缝 = 储能创造的价差（图 B 涂成绿色）。
3. SOC 线贴到虚线了吗？贴住 = 容量约束卡住，扩容有真实收益。

## 第四部分（进阶，可跳过）：套利门槛 1/η²

对偶条件还能推出一个漂亮结论。设最优解在时段 i 谷时买电充电、时段 j 峰时放电：

- 时段 i：λ_i = p_i 且 λ_i = η ν ⟹ ν = p_i / η；
- 时段 j：λ_j = ν/η ≤ p_j ⟹ ν ≤ η p_j；

联立得 **p_j / p_i ≥ 1/η² = 1/0.81 ≈ 1.2346**：峰价至少要贵 23.5% 才值得充放一轮。

初等验证：为在时段 j 母线侧多得 1 度放电，须自池内取 1/η 度，故须在时段 i 母线侧多买 1/η² ≈ 1.2346 度（成本 p_i/η²），收益是省下的 p_j——净收益非负即同一条件。

**数据对照**：本题峰谷比 1.3952 / 0.3713 ≈ 3.76 ≫ 1.2346，套利空间充裕，故储能满幅运行、容量约束成为紧约束（下联 SOC 常贴上限——与图 B 读法呼应）。这个门槛不是外加的经验判据，而是最优性条件的直接推论，论文里可以强调。
