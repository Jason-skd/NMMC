## 0. 一页结论

1. **病根是一个变量别名缺陷，不是建模取向、不是罚则、不是预报。**
   `src/nmmc/model/q3.py::solve_stage` 在 $m=0$（即 0:00 那张日前 LP）算错了变量块偏移：
   `o_dp = n_hn if m else 0` 使 $m=0$ 时首情景块起点 `o_s = 0`，于是 144 个计划变量 $g$
   与"情景 0 块"的前 144 列**占用同一列**，向量末尾另有 144 列从未被引用。$m\ge1$
   （6/12/18 点改单）、内环 `solve_step`、CE 臂 `solve_tail` 的布局都正确——**病灶精确
   地只在日前那一张 LP**。

2. **三条可证伪核验全部通过（§2.2）**：别名残差 $\max|g_{0:108}-a^{(0)}_{36:144}|$
   **恒为 0**；$N_s=1$ 时修正版与题 2 `solve_planning` **逐位等价（$\Delta=0$）**、
   缺陷版每日偏 5,112–15,389 元（11%–99%）——**C3-1 只要写出来就会立刻抓到它**，
   而 C3-1 至今未实现；缺陷版上报的 $\tilde Z$ 不是任何模型的费用。

3. **全年代价 93 万元。** 同预报层、同情景器、同内环、同 SOC 链、同 rng，只把 0:00
   那张 LP 换成修正布局的同款 LP（CF-D）：$Z$ 从 14,199,901 降到 **13,269,655**
   （**−930,246 元 / −7.01%**）。

4. **纵向倒序（问题一）随之消失。** CF-D 比题 2 v6 **便宜 476,161 元**；把 0:00 计划
   直接换成题 2 的两阶段 SAA（CF-A）更便宜——**13,118,789 元，比题 2 v6 省 627,027 元
   （同 v5 口径省 603,689 元），334 天里只有 107 天更贵**。性质 11 / C3-1 要求的
   "题 3 不该更贵"在修正后成立。

5. **"改单权是负资产"这个结论作废。** 在非预期性计划上，改单权值
   **+428,450 元**（CF-B 不改单 13,547,239 → CF-A 改单 13,118,789）。
   附件 3 预报本身（连情景器）另值约 **175,239 元**（CF-B vs 题 2 v5，同代码同口径）。

6. **问题二的机制说反了。** 不是"夜谷报低、白天报高"。实测夜块 $\mathcal B_0$ 整块
   **多买 26.1%**（$\Sigma g/\Sigma n^+ = 1.308$，题 2 是 1.038），错的是**块内形状**：
   0:00–4:00 欠买（比值 0.994 / 0.891）把电池抽到 1,200 kWh 地板，再在 4:00–6:00
   **超买一倍**（比值 2.032）、充电功率 33.4% 的时段顶格。真正被报低的是**晚峰
   $\mathcal B_3$**（0.791，题 2 是 0.968）。

7. **问题三"保险库存被抽干"是缺陷的症状，不是性质 10 的兑现。** 四条修正臂的隔夜
   水位全在 7,893–8,152 kWh（题 2 v6 是 8,167），**没有一条掉到 1,700**。
   ⚠️ 变量档性质 10 / C3-10 现在把"3762 ≪ 8151"写成"最出彩的纵向对比"——**那是在读缺陷**，
   必须撤下。

8. **判据本身也有两处错**（§6）：C3-8「$\Sigma\delta^+\gg\Sigma\delta^-$」按字面在
   CF-D 才成立（$\delta^+/\delta^-=2.31$），而 C3-6「紧急量降一个数量级、接近于零」
   **任何臂都不成立**（最好的 CF-A 是 1/3）——因为 $\mathcal B_0$ 整块无修订机会，
   它那 6 小时的缺口风险与题 2 完全同级，字面判据**结构上不可能过**。

9. **v6 的 $u$ 上界题 3 尚未同步**，但对题 3 是**形式债**：实测轨迹 $\max(u-(n-a)^+)=0$
   （由 $u\cdot c=0$、$u\cdot w=0$ 可证），规划层情景块的 $\Sigma u^{(s)}$ 实测**恒为 0**、
   加上界后 $\Sigma g$ 与 $\tilde Z$ 逐位不变（§7）。要改是为了跨问可比与题 4 继承，不是为了改数。

10. **仓库里 `results/q3*` 全部作废**，包括 12 组消融网格（胜者 F1-L1-LU1-S-b 是在缺陷
    计划器下选出来的）、四档阶梯、四个指定日表、`q3_vs_q2` 图。

## 2. 病因：`solve_stage` 在 $m=0$ 的变量别名

### 2.1 缺陷本体

`src/nmmc/model/q3.py::solve_stage` 的变量布局：

```python
n = n_hn + (2 * n_hn if m else 0) + n_s * n_blk
o_hn = 0
o_dp = n_hn if m else 0                  # 共享 δ+/δ−（仅 m≥1）
o_s  = o_dp + (2 * n_hn if m else 0)     # 首情景块起点
```

`o_dp` 上那个 `if m else 0` 是错的。`o_dp` 应恒为 `n_hn`（δ 块的起点），
`o_s` 上的 `if m else 0` 才是"$m=0$ 没有共享 δ"的正确表达：

| $m$ | `n_hn` | `o_dp` 实际 | `o_s` 实际 | `o_s` 应为 | 重叠列 | 末尾闲置列 |
|---|---:|---:|---:|---:|---:|---:|
| **0** | 144 | **0** | **0** | **144** | **144** | **144** |
| 1 | 36 | 36 | 108 | 108 | 0 | 0 |
| 2 | 36 | 36 | 108 | 108 | 0 | 0 |
| 3 | 36 | 36 | 108 | 108 | 0 | 0 |

$m=0$ 时情景块布局是 $[a^{(s)}(108),\ \delta^{+(s)}(108),\ \delta^{-(s)}(108),\ c,d,u,w,S(145)]$，
于是别名映射精确为

$$g_{[0:108]}\ \equiv\ a^{(0)}_{[36:144]},\qquad g_{[108:144]}\ \equiv\ \delta^{+(0)}_{[0:36]}$$

——**0:00 计划的前 108 格与"情景 0 对后 108 格的试探注入"是同一批列（还错位 36 格），
末 36 格与"情景 0 在 6:00–12:00 的上调量"是同一批列。**

后果不止于多一组等式。目标系数是按块**赋值**（不是累加）写进去的：

```python
obj[o_hn:o_hn + len(cost_hn)] = cost_hn        # obj[0:36] = p[0:36]
...
obj[o_af:o_af + n_free] = pi * p[fe:]          # s=0 时 obj[0:108] = π·p[36:144]  ← 覆盖上一行
```

**情景 0 的赋值把 `obj[0:36] = p[:36]` 整段覆盖掉了**：夜块计划的单价从 $p_t$ 变成
$\tfrac1{12}p_{t+36}$（$N_s=12$），$g_{[108:144]}$ 拿到的是 $\tfrac1{12}\cdot\tfrac12 p_{[36:72]}$。
再叠上被搅乱的偏差等式与平衡式（同一列同时进"情景 0 的 $t$ 时段平衡"和"$t+36$ 时段平衡"），
解出来的既不是计划也不是情景注入。**$g$ 在这张 LP 里几乎没有价格信号**——这就是
$\Sigma g$ 比 $\Sigma a$ 高 11.5%、比题 2 的 $\Sigma g$ 高 11.8% 的直接来源。

### 2.2 三条可证伪核验

复现：`cd experiments/q3 && ../../.venv/bin/python verify_stage0_alias.py`。
对照用的"修正版"是 `experiments/q3/probe_stage0.py::stage0_lp`——逐行复刻 `solve_stage`
的 $m=0$ 分支、只把 `o_s` 改成 `n_hn`。

**核验 1（别名存在）**：15 个抽样日，$\max\lvert g_{[0:108]}-a^{(0)}_{[36:144]}\rvert
= 0.000\mathrm{e}{+}00$ kWh。两批列**逐位相同**，不是巧合。

**核验 2（$N_s=1$ 必须退化成题 2）**：单情景时 $a^{(0)}$ 自由，最优必取 $a\equiv g$、
$\delta=0$，两个目标函数逐项相同，所以阶段 0 LP **必须**与题 2 `solve_planning` 等价：

| 日 | 题 2 $\tilde Z$ | 修正版 $\tilde Z$ | $\max\lvert\Delta g\rvert$ | 缺陷版 $\tilde Z$ | $\max\lvert\Delta g\rvert$ |
|---|---:|---:|---:|---:|---:|
| 40 | 45,746.8280 | 45,746.8280 | **0.0e+00** | 50,858.6608（**+11.2%**） | 1,415.7 |
| 100 | 10,619.8600 | 10,619.8600 | **0.0e+00** | 21,087.4558（**+98.6%**） | 1,090.4 |
| 200 | 44,680.0450 | 44,680.0450 | **7.3e−12** | 60,068.8459（**+34.4%**） | 1,646.7 |

修正版逐位等价，缺陷版每日偏 5,112–15,389 元、单格 $g$ 偏最多 1,647 kWh。
**这正是 C3-1（"强制 $a\equiv g$ + 题 2 情景生成器 ⇒ 逐日精确复现题 2"）要抓的东西；
C3-1 与 C3-2 至今未实现**（`tests/q3/` 下无任何被 git 跟踪的测试文件，
`experiments/` 下也只有 `q2/`）。

**核验 3（$\tilde Z$ 不是费用）**：$N_s=12$ 时缺陷版 $\tilde Z$ 比修正版**低 15.5%**
（15/15 天）。若别名只是"多一组等式"，那是可行域收缩、$\tilde Z$ 必不降；它降了，
说明目标函数也被改写。**仓库里任何用到阶段 0 $\tilde Z$ 的判据（C3-11 阶梯序）都无意义。**

### 2.3 为什么整套自检都过了

`q3_summary.md` 里 C3-3 / C3-7 / C6 / C7 / C8 / $u\wedge c$ / C9 **全过**（残差 $10^{-6}$ 以下）。
原因是这些自检**全部作用在执行层的真实轨迹上**：

- C3-7（$a\equiv g$ 在 $\mathcal B_0$）、C6/C7（对账与守恒）、C8（互斥）只验"给定 $(g,a)$
  的执行是否自洽"——$g$ 是从哪张 LP 出来的、是不是最优，它们**看不见**。
- C9 是 $Z^{\mathrm{PI}}\le Z^{\mathrm{ex\text{-}post}}\le\min(Z^{\mathrm{online}},Z^{\mathrm{CE}})$，
  三条臂共享同一个（错的）$g$，序关系照样成立。
- 恒可行性（性质 2）保证任何 $g$ 都能被 $u$ 兜住，所以 LP 永远不报不可行。

**教训与题 2 v6 的 ③a 判据同源**：只验"轨迹自洽"的自检抓不到"规划层解错了"。
唯一能抓的是**跨模型复现检验**（C3-1/C3-2 这类"退化到已知答案"），而它恰好是唯一没做的。

### 2.4 影响面

- **只污染 0:00 的 $g$**（以及由它派生的一切）。$m\ge1$ 的改单 LP、内环 `solve_step`、
  CE 臂 `solve_tail` 布局都正确。
- $Z^{\mathrm{PI}}$ 臂调的是题 2 的 `solve_planning`，**不受**别名影响（但受 §1.3 的
  SOC 锚与口径污染）。
- 阶梯的 E0/E0-6/E0-6-12 各档、12 组消融网格、$\nu^{\mathrm{end}}$ 扫描**全部**经过
  阶段 0 LP，**全部作废**。

## 5. 第二个缺陷（较轻）：规划层第二阶段缺非预期性

修好别名之后，CF-D（13,269,655）仍比 CF-A（13,118,789）**贵 150,867 元**，
而 CF-A 的 0:00 计划只是题 2 那张**不含任何改单机制**的两阶段 SAA。
"把改单权写进日前 LP"反而比"根本不写"更差，说明写法本身有问题。

**症状定位。** `solve_stage` 在 $m=0$ 把 $\mathcal B_1$–$\mathcal B_3$ 的注入写成
**逐情景** wait-and-see 变量 $a^{(s)}$：12 条情景各有一套 144 格注入，且每套都可以
看到**整条情景**（包括 18:00 之后的实现）。真实的 $\tau_m$ 只看得到已实现前缀
$[0,6\tau_m)$ 加更新预报，所以合法策略必须满足

$$a^{(s)}(\mathcal B_m)=a^{(s')}(\mathcal B_m)\quad\text{whenever } n^{(s)}|_{[0,6\tau_m)}=n^{(s')}|_{[0,6\tau_m)}$$

——即**按 vintage 分组的共享约束**。LP 里没有这组约束，于是阶段 0 相信自己将来能
"按情景量身定制"12 套计划，$g$ 只剩"偏差基准"这一个角色（一阶条件给
$\{a^{(s)}_t\}$ 的加权中位数），对**真实**的单一修订路径失去校准。

**这是松弛而非错误建模**——它给出的 $\tilde Z$ 是真值的下界，性质 11 的"规划目标不劣"
仍成立；但滚动执行会把差额还回来，150,867 元就是这笔账。

**量级判断**：930,246（别名）: 150,867（非预期性）≈ **6 : 1**。
先修别名，非预期性是第二顺位；在修好之前**不要**先动情景生成或罚则。

**可选修法（未实现，按代价排序）**：
1. 最省事：$m=0$ 直接用题 2 的两阶段 SAA 定 $g$（= CF-A，已实测最优），
   把"改单"完全交给 $m\ge1$ 与内环。代价是日前 LP 不再"知道"自己能改单，
   理论上偏保守——但实测它就是最好的一条。
2. 折中：保留 wait-and-see，但按 vintage 把 $a^{(s)}(\mathcal B_m)$ 分组共享
   （情景树而非情景扇）。变量数不增，等式约束增 $O(N_s\cdot 108)$，仍是纯 LP。
3. ⚠️ **不要**用"给 $g$ 加 tie-break/正则"这类办法。实测（`probe_stage0.py` P1 探针）
   在**修正版**上给 $g_{t\ge36}$ 加 $\varepsilon p_t$（$\varepsilon=10^{-4}$）后
   $\Sigma g$ 只动 −0.00%、$\tilde Z$ 动 $<5\times10^{-9}$——修正版**不退化**，
   $g$ 的可修订段有正常价格信号，加正则纯属画蛇添足。

## 7. v6 的 $u$ 上界：题 3 的形式债（不改数，但要改）

题 3 三个 LP 入口（`solve_stage` / `solve_step` / `solve_tail`）都没有
$u_t\le(n_t-a_t)^+$，`run/q3.py` 调题 2 的 `solve_planning` / `solve_recourse`
（PI 与事后臂）时也没传 `u_cap`。**题 3 内部口径自洽（全部 v5），但与题 2 v6 不同口径。**

三条实测（`diag_plan.py` §E、`probe_stage0.py` P2）说明这对题 3 是**形式债**：

1. **实测轨迹已满足上界**：825 个有 $u$ 的时段，$\max(u-(n-a)^+)=0.000\mathrm{e}{+}00$；
   $u\wedge c$ 与 $u\wedge w$ 都是 0 个时段。这是可证的：平衡式
   $u=(n-a)+c+w-d$ 配 $u\cdot w=0$、$c\cdot d=0$ 即得。
2. **规划层情景块里根本不用 $u$**：抽样日每情景日均 $\Sigma u^{(s)}=0.0$ kWh，
   $u^{(s)}\wedge c^{(s)}$ 同时为正的时段 **0 / 8,640**；给情景块加上界后
   $\Sigma g$ 与 $\tilde Z$ **逐位不变**。机制上说得通：题 3 的日内进电通道是
   $\beta^+p=1.5p$ 的加订，比 $\kappa p=5p$ 便宜得多，"5 倍价囤货"的动机被
   性质 10 的门槛 $\beta^+\eta^2=1.215<3.7576$ 自然掐断。
3. 因此上界的经济效果在题 3 上**≈0**；`experiments/q2/README.md` §3 P3 那句
   "故不必改"在**数值上**是对的。

但仍必须改，三个理由：**跨问可比**（题 2 v6 的四条臂都带上界，题 3 不带，
$Z^{\mathrm{PI}}$ 已经因此多背一重污染，§1.3）；**题面一致**（5 倍价电不许入池是
题意，不是数值问题）；**题 4 继承**（波动电价 $p^{(j)}_t$ 下门槛要逐时段重判，
$\beta^+\eta^2$ 可能翻过峰谷比，那时动机就回来了）。

落点：`solve_stage` / `solve_step` / `solve_tail` 加 `u_cap` 形参
（题 2 `model/q2.py` 已有现成写法），上界右端取 $(n-a)^+$；由于 $a$ 是本阶段决策，
$m=0$ 与 $m\ge1$ 同样需要题 2 §6.1 那套**序列线性化到不动点**（外加 C16 型自检）。
⚠️ 不要写成线性的 $u_t+a_t\le n_t$——正号部分必须保留，否则在 $n_t<a_t$ 的时段
会反过来给 $a$ 加上界，把谷时充电一并禁掉。

   的下游，缺陷未修之前任何扫描都是在拟合 bug。性质 11 那句"从情景生成查因"
   在这一轮是错误的指引。
2. **不要把"改单权是负资产""电池被当成可挪用的保险柜"写进论文**。CF-A/CF-D 两条臂
   否证了这个叙事：修正后改单权值 +42.8 万，隔夜水位守在 8,000。

   这条"最出彩的纵向对比"不存在。
4. **不要拿 E0 或 CF-E 当"不改单"基准**——两者的 $g$ 都是"假定后面能改"解出来的，
   属于稻草人。合格基准只有 CF-B（非预期性计划 + 冻结）。

   实测 70.2% 的下调违约金落在电池既不满也不顶的时段，调总量改不了形状错配。
