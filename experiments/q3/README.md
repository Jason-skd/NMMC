### 2.1 反事实臂定义

五条臂与交付臂**共用**预报层、情景器、修订机制、内环随机 MPC、SOC 链与 rng 流，
$u$ 一律**无上界（v5 口径）**——差别只在"0:00 那张 LP"与"是否改单"。

| 臂 | 0:00 计划 | 6/12/18 改单 | $Z^{\mathrm{online}}$ | 用途 |
|---|---|---|---:|---|
| **A** | 题 2 两阶段 SAA（非预期性） | ✅ | **13,118,789** | 最优；证明倒序是缺陷 |
| **B** | 题 2 两阶段 SAA | ❌ | 13,547,239 | **唯一合格的"不改单"基准** |
| C | 缺陷版（不动） | ❌ | ≈仓库 E0 | 回归核对用 |
| **D** | 修正布局的阶段 0 LP | ✅ | **13,269,655** | 量化别名代价（同计划器设计） |
| E | 修正布局的阶段 0 LP | ❌ | 14,128,454 | ⚠️ **不是**合格基准（计划假定能改却被冻结） |

`--cap` 让 A/B 的 0:00 计划走 v6 口径（内环仍无上界，属混合口径，只作探性用）。

## 4. 明确不要做（都已被证否或有反例）

1. **不要先动情景生成器 / 罚则 / $\nu^{\mathrm{end}}$ / 预报候选**——都在阶段 0 LP 下游，
   缺陷未修之前任何扫描都是在拟合 bug。变量档性质 11 那句"从情景生成查因"在这一轮
   是错误指引；排查顺序第一条应是 C3-1。
2. **不要给 $g$ 加 tie-break / 正则**——`probe_stage0.py` P1 已证伪修正版的退化猜想。
3. **不要拿 E0 或 CF-E 当"不改单"基准**（两者的 $g$ 都假定后面能改，属稻草人）。
   E0 比合格基准 CF-B **虚高 232.7 万元**。
4. **不要用调 $\Sigma g$ 总量去"修"$\delta^-$**——70.2% 的下调违约金落在电池既不满
   也不顶的时段，是形状错配不是总量问题。
5. **不要把隔夜水位当题 2/题 3 的分水岭**——修正臂全在 7,893–8,152（题 2 v6 是 8,167），
   C3-10 那条"3762 ≪ 8151，最出彩的纵向对比"是在读缺陷。
