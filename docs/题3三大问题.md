# 题 3 三大问题

日期：2026-09-12。口径：题 2 交付 **L1-P1-R2-smpc**（`results/legacy/q2/L1-P1-R2-smpc/`，v5，\(u\) 无上界），题 3 交付 **F1-L1-LU1-S-b**（`results/q3/F1-L1-LU1-S-b/`，内环随机 MPC），报告期 334 天（2.1–12.31；1 月暖机不计费用）。阶梯对照来自 `results/q3-epochs/`（旧内环 \(\alpha^{\mathrm{rt}}=0.65\)，只作附加问诊断，不与交付 \(Z\) 混用）。

本档只记题 3 相对题 2、相对本档性质 **已经算出来、但主线讲不通** 的三件事。对账、守恒、充放互斥、\(u\wedge c=0\)、C9 序关系（交付臂）全部通过——不是表没填上，是故事反了。

数字不得与题 2 v6（\(u\) 上界）混比：题 3 尚未同步该口径。跨问 SOC 的隔夜口径见《题2-SOC与紧急购电诊断.md》§1。

## 0. 结论先行

题面给题 3 多了两样东西：附件 3 的日内光伏预报，以及 6/12/18 点改计划的权利。本档性质 11 / C3-1 写明：\(a\equiv g\) 时题 2 是严格特例，题 2 最优解在题 3 里永远可行。因此题 3 **不该更贵**；更贵必须当作判定性事故，不得事后解释成“改单本来就有成本”。

实测三条同时成立：

| # | 问题 | 一句话 | 判定条款 |
|---|---|---|---|
| **1** | **纵向倒序** | 预报更好、还能改单，全年仍比题 2 贵 **47.7 万**；273/334 天更贵 | C3-1、性质 11、C3-16 |
| **2** | **日前计划方向反了** | 不可改的夜谷报低（抽电池），可改的白天报高再付半价砍单；\(\delta^+/\delta^-=0.07\) | 性质 7 / 9，C3-5、C3-8 |
| **3** | **保险库存被抽干** | 隔夜水位从约 8000 滑到约 1700；紧急费降到 1/5，发生天数却比题 2 更多 | 性质 8 / 10，C3-6、C3-10 |

不是三件独立的事。0:00 规划器按“后面能改”把 \(\mathcal{B}_0\) 报低、把 \(\mathcal{B}_{1..3}\) 的 \(g\) 报高；白天用修订权给自己擦屁股（问题 2）；夜里 \(g\) 锁死，执行只能放电池，库存逐年兑现、贴底后小残差变紧急（问题 3）；三笔账加总仍打不赢“不改单、高保险”的题 2（问题 1）。

与题 2 的 \(u\) 口径病无关：题 3 交付 \(u\wedge c=0\)，紧急电不是“5 倍价进货通道”。题 3 的病在**规划层没有把“可以不改”当成必须打得过的对照**，滚动时域上修订权变成负资产。

## 1. 问题一：信息和改单权都多了，全年比题 2 更贵

### 1.1 主结果

光伏预报题 3 更好（时段 MAE 22.2 vs 题 2 的 25.6 kWh），负载同一套 L1（31.5）。题 3 每天最多三次改单。现金费用：

| | 题 2 smpc | 题 3 交付 |
|---|---:|---:|
| \(Z^{\mathrm{online}}\) | **13,722,478** | **14,199,901** |
| 差额 | — | **+477,423（+3.5%）** |
| 题 3 更贵的天数 | — | **273 / 334** |
| 基础购电 \(\sum p a\) | （即 \(\sum p g\)） | 13,034,543 |
| 偏差费 \(\frac12\sum p\|a-g\|\) | 0 | **990,517（占 6.98%）** |
| 紧急费 | 980,591（7.15%） | 174,842（1.23%） |

题 3 把紧急费压下来了，**偏差费几乎把省下的紧急费吃光还倒贴**。这不是“改单有成本所以略贵”：特例路径 \(a\equiv g\) 的偏差费为 0，费用应逐字退回题 2。优化器没有走到这条免费可行路径。

性质 11 的精确表述——规划目标上修订权不亏，**滚动在线实测没有保证**——现在不是脚注，是主结果。C3-16 要求年末 SOC 修正后再横向比：题 2 年末 7806 kWh、题 3 年末 1746 kWh，按 \(\nu^{\mathrm{end}}=0.472\) 补库存，题 3 还要再吃亏约 0.3 万，47 万缺口补不上。

### 1.2 指定日也讲不成“题 3 更好”

| 日期 | 题 2 \(Z\) | 题 3 \(Z\) | 题 3 日初 SOC（vs 题 2） | 题 3 当天 \(\delta^-\) |
|---|---:|---:|---:|---:|
| 3.20 | 42,760 | 43,778（更贵） | 5,715 vs 8,298 | 5,281 |
| 6.21 | 20,652 | **24,859（更贵 4,207）** | **2,003 vs 8,966** | **11,884** |
| 9.23 | 54,202 | 49,752（更便宜；题 2 当天紧急 2,520 kWh） | 4,301 vs 7,184 | 9,410 |
| 12.21 | 61,625 | 60,327 | 两边都约 8,000 | 930 |

夏至：两边弃光都约 1.18 万 kWh，题 3 额外付一笔万元级违约金——0:00 按偏高的 \(g\) 报进去，白天再砍。四个指定日里没有“预报 + 调整稳定优于题 2”的故事。

### 1.3 \(Z^{\mathrm{PI}}\) 不能当跨题下界

完美信息下 \(a\equiv g\)、\(u\) 可消，题 2 / 题 3 的 PI 本应同值。实测 12,225,559 vs 12,893,778。实现把逐日 PI 挂在**各自在线轨迹的日初 SOC** 上；题 3 经常低水位进日，PI 天然更贵（与 \(\Delta Z^{\mathrm{PI}}\) 相关约 −0.88）。EVPI 二分解被 SOC 链污染，不能用来讲“题 3 信息价值”。

### 1.4 附加问的梯子撑在坏对照上

`q3-epochs` 阶梯（旧内环，只看形状）：

\[
Z^{\mathrm{E0}}=1587.4\text{ 万}\ \to\ 1514.7\ \to\ 1456.8\ \to\ 1425.7\text{ 万}
\]

E0（只用 0:00、不修订）比题 2 高出 **215 万**，弃电率 22.5%（题 2 为 8.8%）。它仍用**题 3 日前规划器**（LP 里假定后面能改），然后冻结 \(a\equiv g\)。这是“以为能改、其实不能改”，不是 C3-1 要求的“强制 \(a\equiv g\) + 题 2 情景器复现题 2”。用 E0 证明“需要 6/12/18 预报”，是在打稻草人：相对被自己规划器坑过的 E0，日内修订当然值钱；相对题 2，全开修订仍然更贵。

E0 在指定日 12.21 上 C9 倒序：\(Z^{\mathrm{PI}}=59625>Z^{\mathrm{ex\text{-}post}}=59421\)。仓库里没有 C3-1 的复现结果。

## 2. 问题二：日前计划方向反了——夜谷报低、白天报高再砍单

同一天两套相反的错误：不可改的 \(\mathcal{B}_0\)（0–6 点）报少，可改的 \(\mathcal{B}_{1..3}\) 报多。性质 7 要的 6:00 服务水平台阶是“夜里高保险、白天降档”；做到的是反过来。

### 2.1 白天：几乎天天付半价撤单

| | 电量 |
|---|---:|
| 上调 \(\delta^+\)（加订，付 1.5 倍） | 195,300 kWh |
| 下调 \(\delta^-\)（违约，按半价退） | **2,867,134 kWh** |
| 方向比 \(\delta^+/\delta^-\) | **0.068** |
| 有下调的天数 | **333 / 334** |
| 调整行使率（\(t\ge 36\)） | 33.7% |

性质 9「宁存不退」：电池有空位时，多买入池只亏往返损耗 \(0.19p\)，退掉亏 \(0.5p\)，弃掉亏 \(1.0p\)，优先级入池 > 取消 > 弃电，故应 \(\sum\delta^+\gg\sum\delta^-\)。C3-8 按字面判定性。

实测下调是上调的 **15 倍**。99 万偏差费的大头就是这 287 万 kWh × 半价。日末水位均值只有 3762 kWh（上限 10800），不是顶格才退——空仓也在砍单。

机制：0:00 那张 LP 同时锁全天 144 个 \(g\)，并在情景里预演“后面还能改”。可修订块的等待变量 \(a^{(s)}\) 按情景往上盖缺口，\(g\) 作为与这些 \(a^{(s)}\) 比偏差的锚被拉高。到 6/12/18 点真预报往往没那么缺，于是 \(\delta^-\) 爆掉。理论里可修订块的报童分位应降到 0.50–0.725；行为上 \(g\) 仍偏题 2 那种“宁可多备”，再用修订权付 50% 手续费往回改。

### 2.2 夜里：\(\mathcal{B}_0\) 报低，执行只能抽电池

\(\mathcal{B}_0\) 报出后 \(a\equiv g\)，永不可改。性质 7：这一块应按 \(\alpha^\star=0.80\text{–}0.955\) 高保险。0–4 点日均充放（电池侧，334 天）：

| | 充电 | 放电 | 净 |
|---|---:|---:|---:|
| 题 2 | 1,375 | 422 | **净充 ~950** |
| 题 3 | 1,948 | 3,398 | **净放 ~1,450** |

题 3 **334/334 天夜间都在放电**。2 月 1 日：0–4 点放 6,193、充 269；计划前几档 302 / 415 / 437 / 438 / 0 / 0，题 2 同期 1,128 / 1,249 / 460…。谷电约 0.42 元、早峰 0.8–1.2 元，夜里放库存是反套利。执行层没有选择：\(g\) 已锁死，不够就只能放电或付 5 倍。

### 2.3 文档已经开始改口，清单还没改

《题3公式讲解》F25 已写成“实测 \(\sum\delta^+:\sum\delta^-\approx 1:14\)，宁存不退只在电池有余量时成立”。变量档性质 9 与 C3-8 仍要求 \(\sum\delta^+\gg\sum\delta^-\)。一边改口、一边自检仍判不过即故事崩——论文不能两套一起用。

## 3. 问题三：保险库存被抽干，紧急天数不降反升

### 3.1 隔夜水位才是保险指纹

日内 SOC 均值（5444 vs 题 2 的 7060）会把“白天套利循环”和“跨日持仓”混在一起。保险存货看隔夜：

| | 题 1 循环 | 题 2 | 题 3 |
|---|---:|---:|---:|
| 日初均值 | 8,550 | **8,151** | **3,780** |
| 日末均值 | 8,550 | 8,150 | **3,762** |
| 日末最低 | — | 5,779 | **1,200（触底）** |
| 2/1 日初 → 12/31 日末 | — | 8,129 → 7,806 | 8,073 → **1,746** |
| 报告期净变化 | 0 | −323 kWh | **−6,327 kWh** |

2 月 1 日两边几乎一样高（暖机刚结束）。题 2 把水位钉在 8000 附近；题 3 次日日末就掉到 1,879，此后全年在 2000–4500 晃，12 月底只剩 1,746。329/334 天题 2 日初高于题 3。

性质 10 的定性——题 3 保险门槛从 \(\kappa\eta^2=4.05\) 降到 \(\beta^+\eta^2=1.215\)（低于峰谷比 3.76），电池应从“套利 + 保险”退回“以套利为主”，水位低于题 2——**半句是对的**。错在幅度：套利仍要求谷充峰放，题 1 周期态在 8550。预言是 \(\bar S^{\mathrm{Q1}}\lesssim\bar S^{\mathrm{Q3}}<\bar S^{\mathrm{Q2}}\)。实测

\[
\bar S^{\mathrm{Q3}}\ll \bar S^{\mathrm{Q1}} < \bar S^{\mathrm{Q2}}
\]

（隔夜 3780 ≪ 8550 < 8151）。不是“少囤一点保险”，是把套利该留的底仓也吐掉了。《题3公式讲解》F26 用旧数“Q2 均值 6952 → Q3 5395，方向吻合”比的是日内均值，且仍假装满足 Q1 ≲ Q3，不能进论文。

### 3.2 紧急购电：金额降了，故事没圆

性质 8：末次修订后残差 P99 = 149.5 kWh ≪ 放电上限 833，紧急应降一个数量级以上、接近于零；若不然，先查 SOC 是否贴边（C3-6）。

| | 题 2 | 题 3 |
|---|---:|---:|
| 紧急电量 | 221,165 kWh | 43,971 kWh（约 1/5） |
| 紧急费 | 980,591 | 174,842（约 1/5.6） |
| 发生天数 | 167 / 334 | **181 / 334** |
| 发生时段 | 2,174 | 825 |
| \(u\wedge c\) | 539 | **0** |

金额约降到 1/5，不到“一个数量级”（1/10），更不是“接近于零”。**天数反而更多**：更多日子冒出一小截救火。这与水位贴底是同一件事——库存没了，小残差也要 \(u\)。性质 8 自己写的排查顺序，正好指向 §3.1。

\(u\wedge c=0\) 说明题 3 **没有**题 2 v5 那种“5 倍价买来入池”。紧急电更像真缺口；缺口本不该这么频繁。

## 4. 三条是一条链

1. **罚则变了。** 题 2 缺口影子价格是 5 倍，夜谷囤电当保险划算。题 3 多数缺口可在 6 小时内用 1.5 倍加订补，保险门槛掉到 1.215 < 峰谷比 3.76——夜里为防紧急而囤电不再无条件划算。
2. **0:00 规划器按“后面能改”报 \(g\)。** 可改段报高（当锚），不可改的 \(\mathcal{B}_0\) 报低（反正有库存）。→ 问题 2。
3. **白天信息变好，付 50% 把高锚砍掉** → 99 万偏差费，宁存不退被违背。
4. **夜里 \(g\) 锁死且偏低，执行只能放电池** → 夜间净放电，台阶预言被违背。
5. **库存逐年兑现，又不补回到套利水位** → 从 8000 滑到 1700，贴底后小残差变紧急，天数比题 2 还多。→ 问题 3。
6. **三笔账加总，仍比不改单的题 2 贵 47.7 万。** 特例关系在数学上成立，滚动回测里没被用到。→ 问题 1。

一句话：**改单权让日前计划变懒、变歪；电池被当成可挪用的保险柜；预报把歪掉的计划纠正回来时付了半价手续费——手续费 + 低水位，合计打不赢不去改单的题 2。**

评委不需要看 LP。把题 2 / 题 3 的全年费用、日末水位、\(\delta^+/\delta^-\) 三张表一摆，问的就是这件事。

## 5. 论文与实现上现在不能做的事

- 不能把 E0→A3 的降费写成附加问的主答案，除非同时报 **对题 2 交付解的纵向对照**（且 E0 不得冒充题 2）。
- 不能再写 \(\sum\delta^+\gg\sum\delta^-\)、不能再写 \(\bar S^{\mathrm{Q1}}\lesssim\bar S^{\mathrm{Q3}}\)、不能把紧急费“一个数量级 + 接近于零”当已兑现。
- 不能拿未做年末 SOC 修正的裸 \(Z\) 宣称题 3 优于或接近题 2。
- 不能把 `q3-epochs` / `q3-ablation` / `q3-alpha` 的 1425.7 万与交付 1420.0 万混成“题 3 主结果”。
- 交付表「全天购电费」：计划表 \(=\sum pg\)，调整表 \(=\sum(pa+\frac12p|a-g|)\)（不含紧急），题 2 同名列含紧急。摘要表头不得再写“含偏差与紧急费”。

未做、且必须做才能收口的一项：C3-1（强制 \(a\equiv g\) + 题 2 情景器，逐日复现题 2）。做不到，特例关系就只是文档里的句子。

题 4 两条交付线直接继承本题执行层与规划层。这三条不收口，波动电价只会把倒序和抽干放大一遍；题 4 全年回测应排在本题之后。
