## q3-alpha/ — 题 3 旧内环 α^rt 扫描（0.55 / 0.6 / 0.7 / 0.75 全年）

- **是什么**：旧内环（固定融合系数 $\alpha^{\mathrm{rt}}$ 分位压缩）下四档 α 的 334 天全年回测（$Z^{\mathrm{online}}$ ≈ 1,425.7–1,430.5 万），用于论证 α=0.65 的选取。
- **为何退役**：题 3 档 v4（`feat/q3-inner-smpc`）把内环换为在线随机 MPC——$\alpha^{\mathrm{rt}}$ 出身泄漏（0.65 出自题 2 v4 的费用扫描），且分位压缩已被题 2 判"把概率压成必然"年多花 35.3 万元；$\alpha^{\mathrm{rt}}=0.65$ 冻结为 $Z^{\mathrm{CE}}$ 配对诊断，不再扫参。
- **接替者**：`results/q3/F1-L1-LU1-S-b/`（内环 MPC 交付，$Z^{\mathrm{online}}$ = 14,199,901.45 元；α=0.65 对照 $Z^{\mathrm{CE}}$ = 14,284,462.08 元内嵌其 `q3_summary.md`）。α=0.65 的 14 天基线对照臂在 `results/q3-baseline/`（现行实验资产，不随本归档）。
