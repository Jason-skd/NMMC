# C 题带读：微网与外部电网电力调控策略

**这道题一句话**：小区自带光伏板和一块大电池，电价有贵有贱——你要写一个"每天的买电 + 电池充放电计划"，**电便宜时多买（存进电池），电贵时用电池**，保证居民不断电，全年买电总费用越少越好。

**全文结构**：背景两段 → 4 个问题（难度递进的阶梯）→ 附录1（电池参数）→ 附录2（附件说明）→ 附件5（交作业格式）。四个问题共享同一个模型骨架，是"一层层加条件"的关系：

| | 电价 | 负载/光伏 | 新增机制 |
|---|---|---|---|
| 问题1 | 每天相同 | 每天相同（光伏有预测） | 只需保证供需平衡 + 电池电量昼夜循环 |
| 问题2 | 每天相同 | 每天变化 | 断供了要按 **5 倍价**紧急买电 |
| 问题3 | 每天相同 | 靠**预报**（一天 4 次更新） | 计划与调整的偏差按 50% / 1.5 倍结算 |
| 问题4 | 实时波动 | 同上 | 用真实波动电价把问题 2、3 重做一遍 |

## 1. 背景段（第 1 页开头）

> "微网是为解决光伏发电等分布式能源本地消纳，减少并网问题而快速发展起来的小型发用电系统。"

**背景补充**：
- **微网**＝一个小社区自己的"迷你电网"：几块光伏板 + 一块储能电池 + 小区负载（居民用电），可以跟大电网连着，也可以自己转。
- **就地消纳**：光伏发出来的电最好自己当场用掉/存掉，卖回大电网麻烦（"并网问题"）。
- **核心玩法**：> "在外网电价较低……的时间段，为储能设备充电，并在外网电价较高的时间段释放电能。" 这就是**峰谷套利**——中国居民/工业电价普遍分时段（深夜"谷"便宜、傍晚"峰"贵），相当于"低价囤货、高价用存货"。

**整段理解**：这道题的商业本质就是一句话——**利用价差，用电池"倒卖"电能省钱**。所有四问都是围绕这个玩法的变体。

> "尽可能精准地给出微网的购电量和储能设备的充放电量，使得微网提供的电力既能满足小区的负载，又尽可能节省微网的购电费用。"

**整段理解**：这是全题的目标函数与硬约束的官方版表述——**不断电是底线，省钱是目标**。后面所有问题都是这句话在不同信息条件下的具体化。

## 2. 问题 1：理想情况下的单日计划

> "若每天的电价和小区负载相同，同时给出光伏发电功率一天的预测数据……储能设备在 0:00 和 24:00 的储电量相同。请在每天 0:00 制定微网当天的计划购电策略的数学模型。"

**背景补充**：
- 既然每天电价、负载都一样，**解出一天的计划就等于解出全年**——所以问题 1 其实是"解一个典型日"。
- "0:00 和 24:00 储电量相同"＝**电量昼夜循环**：今天占电池的便宜，明天要还回去，不能靠"把电池抽干"省一次性钱。这是让问题有稳定解的关键约束。
- 这在数学上就是一个**线性规划（LP）**：决策变量是每个 10 分钟"买多少电、充多少、放多少"；约束是供需平衡、电池电量上下限、充放电功率上限；目标是总购电费最小。非数学说法：像"预算分配拼图"，Excel 的"规划求解"都能做，Python 用 `scipy`/`pulp` 更方便。

**整段理解**：问题 1 是全题的地基模型——把"买电、充电、放电、电池状态"写成一个自洽的优化问题，后面三问只是不断往这个骨架上加新规则。

## 3. 问题 2：日子各不相同 + 断供电罚 5 倍

> "小区负载和光伏发电功率随时间变化……如果低于负载，需向外网紧急购电，其电价是交易时刻电价的 5 倍。"

**背景补充**：
- 现在要用**附件2 的全年真实数据**（负载、光伏实际功率），一天一天地做计划，输出从 2025.2.1 到 12.31。
- **紧急购电 = 5 倍价**，是惩罚性条款：计划执行中一旦供不应求，就得天价补购。它逼你的计划留有余量。
- ⚠️ **读题要抠的一个点**：题目说"在每天 0:00 制定当天的计划"，但没明说 0:00 时你**掌握什么信息**——是已经知道当天真实负载/光伏（完美信息，那紧急购电理论上不会发生），还是只能按附件1 的典型日做计划、真实一来就出现缺口（那 5 倍罚则才真正咬人）？这是本题最重要的**建模假设**，必须在论文里明确声明并自圆其说。
- 另一个细节：附录1 给的初始电量是 **1 月 1 日**的，输出却从 **2 月 1 日**开始——这一个月"空档"要你们自己处理并说明（合理做法：从 1.1 起完整模拟，报告从 2.1 起截取）。
- 表3 指定的四个日期 **3.20 / 6.21 / 9.23 / 12.21** 恰好是春分、夏至、秋分、冬至——官方选它们代表四季的典型日，答题时可以顺手点出这层用意。

**整段理解**：问题 1 是"完美的一天"，问题 2 是"三百多个各不相同的日子 + 一条天价保险条款"——模型没变，但要从解一次变成**按天滚动求解一整年**，工作量从数学转到了数据处理。

## 4. 问题 3：计划赶不上变化，靠预报打补丁

> "在每天 0:00、6:00、12:00 和 18:00 可获得未来 24 小时整点的光伏发电功率预报……计划购电量高于调整购电量的部分，违约电价是交易时刻电价的 50%。调整购电量高于计划购电量的部分，超出部分的电价是交易时刻电价的 1.5 倍。"

**背景补充**：这条规则像"餐厅订菜"：
- 早上订了 100 份（计划），中午改主意只调到 80 份——**多订的 20 份按半价赔违约金**（50%）；
- 反过来订了 80 份、临时要加到 100 份——**补订的 20 份加价 50%（1.5 倍）**；
- 真到开饭还不够——**紧急采购 5 倍价**兜底。

于是出现一个经典的风险权衡：**计划订多→付违约金，订少→付加价/罚金**。预报一天更新四次（附件3），你可以选择只在 0:00 订，也可以 6/12/18 点各改一次——改有改的代价，不改有不改的风险。

**整段理解**：问题 3 引入了"**预报不准 + 分层惩罚**"，模型从单次优化变成**多阶段决策**（先订、再改、再兜底）。题目最后那问"分析是否需要引入其他时刻的预报"就是让你做**对比实验**：只用 0:00 预报 vs 每次预报都调整，算总账比较——这是论文里最好出彩的分析部分。

## 5. 问题 4：电价也动了

> "实际上，外网的电价也是实时波动的。请针对波动电价，建立微网当天购电策略的数学模型。"

**整段理解**：前三个问题都假设电价天天相同（附件1 那张表），问题 4 换上附件4 的**全年真实波动电价**，把问题 2 和问题 3 的全部逻辑重跑一遍（输出 result4-2 和 result4-3 两个文件）。注意 5 倍、50%、1.5 倍这些倍率现在都挂在**波动价**上——峰时紧急购电会更痛，策略会自然变得更保守。这是"阶梯"的最后一级：**电价、负载、光伏全都随时间变**。

## 6. 附录 1：电池参数（全题的"物理规则"）

> "最大容量为 12000 kWh，最大充放电功率为 5000 kW……电量必须保持在 1200-10800 kWh 之间，充放电效率为 90%。"

**背景补充**——这里藏着全题最容易翻车的概念，**kW 和 kWh 的区别**：
- **kW 是功率**（水龙头开多大），**kWh 是电量**（一共接了多少水）。表格里的数据单位是 kW，交结果的单位是 kWh——**每个时间段都要乘以时长**（10 分钟 = 1/6 小时，如 5000 kW × 1/6 h ≈ 833.3 kWh）。
- **效率 90%**：电网充 100 度进电池，只存下 90 度；放电 likewise 再打一次九折——一来一回只剩约 81%。所以"谷充峰放"要**价差足够大**才划算，价差不够就宁可直买。这个直觉你的模型会自动算出来，但你要能解释它。
- 运行区间 1200–10800（标称 12000，但实际不许充满放光）——约束别写错成 0–12000。

**参数速查表**（建议抄在草稿纸首行）：

| 参数 | 数值 |
|---|---|
| 储能标称容量 | 12000 kWh，**运行区间 1200–10800 kWh** |
| 最大充/放电功率 | 5000 kW |
| 充放电效率 | 90%（充放各打九折） |
| 初始电量 | 6000 kWh（2025.1.1 0:00） |
| 紧急购电 | 交易时刻电价 × 5 |
| 计划 > 调整的部分 | 交易时刻电价 × 50%（违约金） |
| 调整 > 计划的部分 | 交易时刻电价 × 1.5 |
| 时间粒度 | 购电按 10 分钟；充放电报表按 4 小时块 |
| 初始信息 | 附件1：典型日电价/负载/光伏预测；附件2：全年实际负载/光伏；附件3：一天 4 次光伏预报；附件4：全年波动电价；附件5：结果模板 |

## 7. 附录 2 + 附件 5：数据与交作业

**整段理解**（操作层面，但丢分高发区）：
- 四个数据附件分工：附件1 是"典型日"，附件2/3/4 是全年实际/预报/电价——注意 **0:00+1 表示当天 24:00** 这种记号约定。
- 结果文件有**五个**（result1 / result2 / result3 / result4-2 / result4-3），每个的工作表名、时间范围、单位（kWh）都规定死了（表4 还给了紧急购电的填写示例）。**先下载附件5 的模板，照着填**——评委先查格式，格式错=白做。

---

带读完毕。C 题的骨架是：**问题1（建 LP 骨架）→ 问题2（全年滚动 + 罚则）→ 问题3（预报 + 多阶段调整）→ 问题4（波动电价全套重跑）**，贯穿始终的物理内核是附录1 那块电池（功率上限、90% 效率、电量区间）。

与 B 题正好相反：B 的难点在"没做过的工程"，C 的难点在"做到底的细心"——数据量、单位换算、输出格式、以及问题 2/3 里那几个必须自己声明清楚的假设（0:00 时掌握什么信息、1 月空档怎么处理、光伏多余能不能弃）。
